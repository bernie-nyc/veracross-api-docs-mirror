# General Principals

API Plus for Academics is based off of the IMS Oneroster spec, If your integration doesn’t require OneRoster compliance, consider using our [Data API](https://api-docs.veracross.com/docs/docs).

We are [certified](https://site.imsglobal.org/certifications/veracross/veracross-lms) in a subset of the IMS OneRoster 1.1 standards:

- REST Data Provider Rostering Core
- REST Data Provider Rostering Optional
- REST Data Provider Gradebook Push Core
- REST Data Consumer Gradebook Pull Core

> Interested in becoming a Veracross Partner? Visit our [partnership form](https://www.veracross.com/integrations/become-a-partner/) to get more info.


> Note: In order to use the API, you must have a pre-approved OAuth Application configured. This includes our API Sandbox and for each school you work with.
